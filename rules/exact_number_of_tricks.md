# EN 

On this board to make the contract declarer must make the exact number of tricks bid. Making X overtricks is scored as going X down. If the contract is doubled or redoubled overtricks score like doubled/redoubled undertricks.

# PL

lewy wpadkowe z (re)kontrą.
